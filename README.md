# Berqateam Enterprise Website

Website statik untuk Berqateam Enterprise, sedia dipublish menggunakan Vercel.

## Publish ke Vercel

1. Upload folder ini ke repository GitHub.
2. Di Vercel, pilih **Add New → Project**.
3. Import repository GitHub tersebut.
4. Pilih **Other** sebagai framework dan klik **Deploy**.

Tiada `ngrok`, backend atau database diperlukan.
